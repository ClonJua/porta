Arquitectura Azure & Machine Learning

Azure Azure ML FastAPI CRISP-DM ETL

Solución orientada a la predicción de prediabetes a partir de un conjunto de preguntas simples. Se aplicó la metodología CRISP-DM, abarcando desde la comprensión del negocio hasta la fase de despliegue. El proyecto incluyó la transformación de un dataset en Excel hacia un contenedor en Azure, seguido del entrenamiento y versionado del modelo en Azure Machine Learning. La demo pública se encuentra temporalmente inactiva por motivos de costo: diabetesazure.onrender.com (diabetesazure.onrender.com).

Objetivo

Predecir riesgo de diabetes a partir de preguntas cortas, permitiendo una orientación inicial.

Stack

El proyecto se apoya en una arquitectura de Azure completamente gobernada, compuesta por Data Factory, Data Lake, Machine Learning, Endpoints y Power BI.
